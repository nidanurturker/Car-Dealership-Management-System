# Car Dealership Management System

A desktop application developed using C# and Windows Forms to manage vehicle and dealership records.

This is one of my first software development projects, created to practice C# programming, database operations, and desktop application development.

## Technologies Used

- C#
- Windows Forms
- .NET Framework
- Entity Framework 6
- Microsoft SQL Server
- LINQ

## Features

- Add new vehicle records
- List registered vehicles
- Update vehicle information
- Delete vehicle records
- Manage vehicle and dealership relationships
- Perform database operations using Entity Framework

## About the Project

This project represents my first steps in software development. It helped me gain hands-on experience with C#, Windows Forms, relational databases, and CRUD operations.
